# style

The diagram standard: [diagrams.md](diagrams.md) holds the rules, levels, layout, lint checks and the frontmatter block, classDefs and label forms every diagram carries, and [diagram-templates.md](diagram-templates.md) the template for each level. A diagram copies the frontmatter and class lines byte for byte, and `merrow diagram lint` checks the copy. Role colours live here. Identity colours for a product come from a reference repo layered on top.
